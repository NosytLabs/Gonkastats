# GonkaStats

An independent Gonka network observatory by Nosyt Labs. The application is being built from the user-approved research brief, with source-attributed data, read-only RPC integration, community tools, and an original visual identity.

This repository is separate from Slipvolt and other Nosyt Labs projects. No wallet key or paid inference is needed for public analytics.

Implementation, source contracts, tests, and runnable preview are added in the next application commit.
